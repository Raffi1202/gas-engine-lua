Gas Engine Carb

Manual, Version 0.13.0 · as of 22.11.2026

Gas Engine Carb is a full-screen widget for FrSky radios running Ethos. It shows the telemetry of a carburettor engine, for example with FrSky AES: cylinder temperatures, RPM, tank, batteries, power switch and reception. It warns with colour, voice and vibration and keeps a list of your flights.

Testing status: Tested on an X18RS (Ethos 26.2.0) with a telemetry simulator (48 sensors, receiver SR10 Plus): sensor search, power switch, batteries, language. Tested in the Ethos simulator: all pages at 800×480 and 480×320, German and English. Not yet tested: a real flight, every menu item on the radio, announcements in flight, the flight list on the radio, radios other than the X18RS.

1 What you need

  • A FrSky radio with Ethos 26.1 or newer and a colour display (X20, X18, X14, X10 and others).
  • FrSky Suite on your computer (for installing), or a card reader.
  • The file Gas-Engine-Carb-0.13.0.zip from the GitHub release.
  • A model with telemetry: at least RPM or cylinder temperature. Everything else is optional.
  • A three-position switch for off / ignition / choke (for the flight list and the «engine off» alarm).

2 Install

With FrSky Suite (recommended)

  1. Connect the radio to the computer by USB and choose Ethos Suite on the radio.
  2. Open FrSky Suite and choose Lua library.
  3. Click Install from local ZIP and choose Gas-Engine-Carb-0.13.0.zip. Do not unzip it first.
  4. Disconnect the radio and restart it.

Without Suite, via the SD card

  1. Unzip the file on the computer. It contains the folder gas_carb.
  2. Copy the whole folder to the radio's SD card into scripts/, i.e. SD:/scripts/gas_carb/.
  3. On a Mac, run dot_clean -m on the folder afterwards, otherwise hidden files get in the way.
  4. Restart the radio.
The X18RS with Ethos 26.2 loads scripts from the SD card only. If the folder is in the internal memory (RADIO), the widget does not appear in the list.

3 Set up the screen

  1. Select the model you want the widget in.
  2. Press DISP and add a new screen. Choose the layout full screen (one widget across the whole screen, no title).
  3. Tap the empty area and choose Gas Engine Carb.
  4. You now see page 1. Without sensors there are dashes everywhere, which is correct.
Compact view: if you choose the layout with top and bottom bar (one widget) instead of «full screen», the widget shows a compact page by itself (chapter 5). In an even smaller area it shows «full screen only».

4 Assign sensors

  1. Let Ethos find the sensors first: Model › Telemetry › Discover sensors.
  2. Long-press the widget and choose Configure widget.
  3. At the top, press Search next to Find sensors automatically. The search runs for a few seconds in steps and only fills empty fields.
  4. Close the menu. After a few seconds the widget briefly shows «n sensors newly assigned». Then open the menu again.
  5. If several sensors match a field, the top shows «Several sensors match, please check:», below it the field, the count and which sensor was chosen. Check these fields in their group and choose by hand if needed.
  6. Assign by hand what the search cannot know: Engine switch (3 positions), Throttle (channel), Mute (switch) and the two status bar switches.
  7. Set Number of cylinders, Tank capacity and for each battery the role, cells and type.

The search recognises sensors by their FrSky ID (application ID) and by known names. A deleted sensor («---») counts as empty and is filled again.

6 Warnings and alarms

Every monitored value has two thresholds. Warning: field and message line orange, the announcement plays. Alarm: red, announcement and, if switched on, vibration. As long as the condition lasts, the announcement repeats every «Repeat every» seconds (default 30 s). It stops as soon as the value is good again. At least 3 s lie between two announcements. The mute switch silences all announcements; the colours stay.

MessageWhenLevel
TELEMETRY LOSTNo telemetry. When it returns: «Telemetry recovered».Warning
ENGINE OFFEngine stopped although the engine switch is on ignition (after the start delay).Alarm
CHOKE OFF!Choke on, engine running and warm or throttle high.Warning
POWER SWITCH FAULTThe power switch reports failsafe, lost receiver, no signal, overload or a faulty channel.Alarm

All limits with their announcements are listed with the setting in chapter 8.

Alarm also with motor off. With the motor switch at Off, all warnings and alarms still come (factory setting). In the menu group Alarm also with motor off you can clear the tick per limit; the switch all sets every tick at once. Without the tick, only tone, announcement and vibration of that value are silent while the motor switch is at Off; the display stays orange or red. When the switch is back at ignition, the announcement comes again. Without an assigned motor switch the setting has no effect. ENGINE OFF, POWER SWITCH FAULT, TELEMETRY LOST and CHOKE OFF! always come.

7 Operation

Start a flightEngine switch from off to ignition. A paused flight continues («Flight resumed»).
End a flightEngine switch to off. Question «Flight finished?»: YES, FINISHED saves the flight, NO, ONLY A PAUSE keeps it open.
RefuelledButton REFUELLED on page 1, then YES, REFUELLED. Fuel used goes to 0, the tank to 100 %.
Without touchThe rotary encoder changes pages. Questions, REFUELLED and the flight list need touch in this version.
MuteFlip the mute switch.

With Lua Studio

If you have the PC program Lua Studio, it creates a file SD:/scripts/studio/modelname.gas_carb.lua per model (special characters and umlauts in the name become «_»). Settings, limits and the boxes of the compact view or page 1 then come from this file, and the menu shows «Studio file loaded». Changes you make in the menu afterwards are stored in modelname.gas_carb.funke.lua; the button Back to Studio state discards them after a question. Without a Studio file the button is called Back to defaults and resets all settings, sensors stay. If the file is broken or too new, a note shows at the bottom for 8 s, then a «!» top right, and the widget works as without Studio.

Cylinders and tank in your own layout (from this version): in Lua Studio choose the display type zylinder for the value «highest cylinder temperature» or tank for «tank %». The box then shows all cylinder columns or the tank column with the REFUELLED button, exactly as on page 1, scaled to the box (minimum 160 × 220 pixels at 800 pixel width). Each type once per view.

In Lua Studio the setting is called «also with motor off» (field beiMotorAus). A limit entry without a number never changes the factory limit; an alarm is only switched off completely with «off».

Studio layout not showing?

  • Copy the file to scripts/studio/ (SD card or radio memory, all three places are searched).
  • One layout for all models: save the file as Standard.gas_carb.lua. Order: choice in the widget menu, file of the model, Standard file, built-in display. The menu shows «Default (all models)». Changes on the radio stay per model. A model named «Standard» uses the file as its own model file.
  • If the file name does not match the model name: widget menu › Studio layout › pick the file (place in brackets).
  • Other window size: the closest view is scaled, note «Studio: view 800x480 adapted» for 5 s.
  • Line at the bottom «Studio: file faulty (…)» or «Studio: no matching view»: export the file again from Lua-Studio.

10 Update and remove

Update: install the new ZIP the same way. Settings, tank, flights and assignments stay, across several versions.

Upgrading from Motoren Vergaser (up to 0.9.0): the widget was renamed (folder gas_carb). Choose the widget again on the model's screen and assign the sensors with «Search»; settings, tank and flights of the old version are not taken over. A Lua-Studio file with the old name (.motoren_vergaser.lua) is still read once; re-transfer it from Lua-Studio. Then delete the old folder SD:/scripts/motoren_vergaser/. Remove: delete it in FrSky Suite under Lua library or delete the folder SD:/scripts/gas_carb/; the saved data in its daten/ subfolder goes with it.
